# Django Study Project

Django 수업 실습 프로젝트입니다.

## 주요 기능

- Bookmark 목록 및 상세 화면
- Blog 게시글 목록 및 상세 화면
- 연도별, 월별, 일별 아카이브
- Django 관리자 페이지
- 클래스형 View 사용

## 개발 환경

- Python 3.14
- Django 6.1
- SQLite
- macOS
- Visual Studio Code
